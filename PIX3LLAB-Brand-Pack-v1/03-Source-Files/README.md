# PIX3LLAB — Sorgenti

Questa cartella contiene il materiale necessario per modificare o implementare il sistema visivo. Non è la cartella da cui prelevare gli asset da pubblicare: per quello usare `../Definitivi/`.

## Struttura

- `Logo/` — copie sorgente degli SVG e raster di lavoro;
- `Font/Dogica/` — font selezionati, informazioni e licenze SIL OFL 1.1;
- `Token CSS/` — token del sistema visivo per la futura implementazione web.

Il font Early GameBoy, valutato ma non selezionato, è conservato nel registro di processo sotto `../02 - Processo/02 - Rifinitura/Font scartati/`.
