# PIX3LLAB — Asset definitivi

Questa cartella contiene esclusivamente gli asset approvati per l’uso pubblico del brand. Le varianti non sono duplicati: sono organizzate per **formato** e **contesto di sfondo**.

## Struttura

| Percorso | Contenuto |
|---|---|
| `SVG/` | file vettoriali master da usare nei siti, README, UI e stampa |
| `PNG/` | esportazioni pronte per anteprime, avatar e piattaforme che non accettano SVG |
| `Guide/` | griglia di costruzione SVG/PNG e specifica geometrica JSON condivisa da light e dark |

## File

| File | Uso |
|---|---|
| `SVG/PIX3LLAB-mark.svg` | marchio Pixel Triade per avatar, badge, icone e header |
| `SVG/PIX3LLAB-favicon.svg` | favicon e icona minima |
| `SVG/PIX3LLAB-wordmark.svg` | wordmark vettoriale PIX3LLAB |
| `SVG/PIX3LLAB-lockup-light.svg` | lockup ufficiale su fondo chiaro |
| `SVG/PIX3LLAB-lockup-dark.svg` | lockup ufficiale su fondo ink/scuro; la cornice strutturale del marchio passa da ink a paper |
| `PNG/…` | anteprime raster corrispondenti agli asset SVG principali |

## Specifica approvata

- Pixel Triade, variante **B / Tecnica**;
- cornice 10%, pixel 20%, distanza 10%;
- wordmark Dogica Bold e descriptor Dogica Pixel, convertiti in tracciati nei file SVG;
- colori: ink `#17201a`, paper `#f3f0e6`, arancione `#ff6534`;
- nel lockup scuro non viene aggiunto un contorno: è la cornice strutturale del marchio a passare da ink a paper; geometria e dimensioni restano identiche alla variante chiara.

I font sorgente e le relative licenze SIL OFL 1.1 restano in `../04 - Sorgenti/Font/Dogica/`; non sono necessari per visualizzare questi SVG, perché il testo del marchio è vettorializzato.
